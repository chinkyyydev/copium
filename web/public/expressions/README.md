# Expression art drop zone

Put the 15 upscaled expression images from the Niji roll here, named exactly
as [brand/11-expression-pack.md](../../../brand/11-expression-pack.md) specifies:

```
expr-smug.png          expr-laughing.png      expr-cryingsmile.png
expr-embarrassed.png   expr-shocked.png       expr-sleepy.png
expr-overloaded.png    expr-maxcopium.png     expr-trustmebro.png
expr-gremlin.png       expr-loading.png       expr-systemerror.png
expr-evilgrin.png      expr-wholesome.png     expr-flustered.png
```

The chat page auto-detects each file — any expression without art falls back
to the built-in placeholder, so you can drop these in one at a time as the
roll gets curated. Square crops work best (the stage is 1:1). Start with
`expr-smug.png` — it's the default face and the greeting.
